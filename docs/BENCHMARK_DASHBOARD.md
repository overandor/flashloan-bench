# Benchmark Dashboard

## Overview

This dashboard displays flash-loan strategy benchmarking results, including throughput, latency, and profitability metrics.

**Status:** Dashboard not yet deployed. This is a planning document for future dashboard implementation.

## Metrics Displayed

### Throughput
- Strategy evaluations per second
- Historical throughput trends
- Comparison across different strategies

### Latency
- RPC call latency (p50, p95, p99)
- Block time latency
- Fork timing results

### Profitability
- Expected profit per strategy
- Gas cost analysis
- Slippage impact
- Execution probability

## Current Results (Local)

Based on local benchmark runs:

- **Strategy evaluation throughput:** ~2.89M evals/sec (Python harness)
- **Anvil fork timing** (ethereum.publicnode.com, 300 samples):
  - `eth_blockNumber`: p50 0.311ms, p95 0.499ms, p99 0.892ms
  - `eth_call` (WETH totalSupply): p50 0.452ms, p95 0.738ms, p99 0.920ms

## Dashboard Implementation Options

### Option 1: Simple Static Page
- HTML/CSS/JavaScript dashboard
- Load results from JSON files in `results/`
- Deploy to GitHub Pages
- Pros: Simple, no backend required
- Cons: No real-time updates

### Option 2: React + Vercel
- React frontend with real-time data
- Vercel deployment
- Pros: Modern UI, easy updates
- Cons: Requires frontend development

### Option 3: Grafana + Prometheus
- Time-series database
- Rich visualization options
- Pros: Professional monitoring
- Cons: Complex setup, overkill for simple benchmarks

### Option 4: Python Streamlit
- Python-based dashboard
- Direct integration with benchmark harness
- Pros: Fast to implement, data already in Python
- Cons: Requires Python server

## Recommended Implementation: Streamlit

Streamlit is recommended because:
1. Data is already in Python (benchmark harness)
2. Fast to implement (single Python file)
3. Built-in charts and visualizations
4. Easy deployment (Streamlit Cloud)

### Example Streamlit Dashboard

```python
import streamlit as st
import json
import plotly.express as px
import plotly.graph_objects as go

st.set_page_config(page_title="Flash Loan Benchmark Dashboard", layout="wide")

st.title("Flash Loan Benchmark Dashboard")

# Load benchmark results
try:
    with open('results/benchmark.json', 'r') as f:
        benchmark_data = json.load(f)
except FileNotFoundError:
    st.warning("Benchmark results not found. Run ./scripts/run_benchmark.sh first")
    st.stop()

# Load fork timing results
try:
    with open('results/fork_timing.json', 'r') as f:
        timing_data = json.load(f)
except FileNotFoundError:
    timing_data = None

# Display throughput
st.header("Throughput Metrics")
col1, col2, col3 = st.columns(3)
col1.metric("Evaluations/sec", f"{benchmark_data.get('evals_per_sec', 0):,.0f}")
col2.metric("Total Evaluations", f"{benchmark_data.get('total_evals', 0):,.0f}")
col3.metric("Duration (s)", f"{benchmark_data.get('duration', 0):.2f}")

# Display latency if available
if timing_data:
    st.header("RPC Latency")
    
    for metric in ['eth_blockNumber', 'eth_call']:
        if metric in timing_data:
            data = timing_data[metric]
            fig = go.Figure()
            fig.add_trace(go.Histogram(x=data, name=metric))
            fig.update_layout(
                title=f"{metric} Latency Distribution",
                xaxis_title="Latency (ms)",
                yaxis_title="Count"
            )
            st.plotly_chart(fig, use_container_width=True)
            
            # Display percentiles
            sorted_data = sorted(data)
            p50 = sorted_data[len(sorted_data) // 2]
            p95 = sorted_data[int(len(sorted_data) * 0.95)]
            p99 = sorted_data[int(len(sorted_data) * 0.99)]
            
            col1, col2, col3 = st.columns(3)
            col1.metric("p50", f"{p50:.3f}ms")
            col2.metric("p95", f"{p95:.3f}ms")
            col3.metric("p99", f"{p99:.3f}ms")

# Configuration
st.sidebar.header("Configuration")
st.sidebar.text("RPC Configuration")
st.sidebar.text_input("RPC URL", value="https://ethereum.publicnode.com")
st.sidebar.number_input("Sample Size", value=300)
st.sidebar.button("Run Benchmark")

# Footer
st.markdown("---")
st.markdown("Generated by Flash-Loan Benchmark Kit")
```

## Deployment

### Local Development

```bash
pip install streamlit plotly
streamlit run docs/benchmark_dashboard.py
```

### Streamlit Cloud Deployment

1. Push code to GitHub
2. Connect repository to Streamlit Cloud
3. Configure environment variables
4. Deploy

### GitHub Pages Deployment (Static)

1. Generate static HTML from Streamlit
2. Push to `gh-pages` branch
3. Enable GitHub Pages
